# 새:공간 공간취향 웹 MVP

바로 브라우저에서 실행 가능한 프론트엔드 MVP입니다.

## 실행
`index.html`을 브라우저에서 열거나 정적 웹호스팅에 폴더 전체를 업로드하세요.

- 태블릿: `index.html?source=tablet`
- QR 모바일: `index.html?source=qr_mobile`

## 현재 구현
- INTRO → 닉네임 → 공간 선택 → 공간 확인 → 활동 → 중요조건 → 제약수용 → 하루 WTP → 행동의향 → 연령 → 결과카드
- REAL/IMAGINE 공간 데이터 분리
- 활동 기반 결과 타입
- 태블릿/QR source 구분
- 브라우저 localStorage 임시 응답 저장
- use/host 응답자에게 실제 이용기회 CTA 노출
- 모바일 반응형

## 행사 전 반드시 연결할 것
1. 실제 12개 공간 이미지: `app.js` CONFIG.spaces 각 `image` 필드에 경로 입력
2. 공간별 실제 이용조건 최종 확정
3. 서버 DB/API 연결: 현재 localStorage는 한 기기 안에만 저장되는 프로토타입
4. 후속신청 연락처 + 개인정보 수집·이용 동의
5. CSV/관리자 페이지
6. 행사장 태블릿에서 전체 화면/자동 초기화 실기기 테스트

## 디자인
`assets/booth-reference.png`는 사용자가 제공한 부스 디자인 참고 이미지입니다.
타이틀은 부스와 비슷한 굵고 둥근 인상을 CSS 시스템 폰트로 구현했습니다. 실제 사용 폰트 라이선스/웹폰트가 준비되면 교체하세요.

## v6 관리자/데이터 저장
- 태블릿 1대 전용으로 단순화했습니다.
- 완료 응답은 브라우저 localStorage의 `spaceTasteResponses`에 누적됩니다.
- `admin.html`을 열면 같은 `index.html?admin=1` 관리자 모드로 이동합니다.
- 관리자 화면: 총 완료, 실제 이용/운영 의향, 프로그램 운영 의향, 제약 수용, 공간/이용목적/지불의향/행동의향/연령대 집계, 최근 응답.
- CSV 다운로드는 UTF-8 BOM을 포함해 Excel 한글 깨짐을 줄였습니다.
- 전체 삭제는 `새공간삭제`를 직접 입력해야 실행됩니다.
- 중요: 브라우저 방문기록/사이트 데이터를 삭제하면 localStorage도 사라질 수 있으므로 행사 중간과 종료 직후 CSV 백업을 권장합니다.

## v8 참가자 비주얼 리디자인 (디자인만 변경)
- 부스 아이덴티티 정렬: 크림 + 짙은 초록 + 라임/연두 + 오렌지 포인트, 통통 튀는 라운드 톤.
- 타이틀 서체를 부스와 비슷한 둥근 인상의 **Jua(주아체, SIL OFL)** 로 교체하고 `assets/fonts/`에 동봉 → 오프라인에서도 동일 서체 표시(서비스워커 캐시 포함). 본문은 시스템 고딕 유지.
- 이모지 아이콘 전면 제거(이용목적·행동의향 등) → 손그림/타이포·하우스형 진행표시·새:공간 로고(SVG)로 대체.
- 공간 선택 화면을 실물 '공간카드' 느낌으로(코드 스탬프·사진·REAL/IMAGINE 구분).
- 제약 화면 색을 브랜드(초록+오렌지)로 정리(기존 브라운 제거).
- SaaS형 그림자/그라데이션 대신 인쇄물 느낌의 **솔리드 오프셋**과 절취선/스티커 요소 사용.
- **결과화면**을 인스타 스토리용 '디지털 공간취향 카드'로 재설계: 라임 하이라이트 타이틀 + 실제 공간 폴라로이드(워시테이프·코드 스탬프) + @new.gonggan 핸들. 촬영 가이드·리워드·버튼은 카드 바깥에 분리.
- **iPad 가로 최우선**: 결과 카드가 가로 1화면(≈834px)에 스크롤 없이 들어오도록 정렬. QR 모바일 반응형 유지.
